# CodeAlpha Stock Trading Platform

A Java console-based application that simulates a basic stock trading environment.

## Features
- Display available stocks and prices
- Buy and sell stocks
- Track available cash balance
- View portfolio and stock holdings
- Calculate total portfolio value and assets
- Validate stock selection and quantity

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Arrays
- Scanner for user input

## How to Run
1. Download `StockTradingPlatform.java`.
2. Open it in a Java IDE or online Java compiler.
3. Compile and run the program.
4. Choose an option from the menu to view stocks, buy, sell, or view your portfolio.

## Project Type
Console-based Java application developed as part of the CodeAlpha Java Programming Internship tasks.
